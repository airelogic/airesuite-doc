AireFlow Release Notes ​

Version: 2.42.0
Release Date: 21 October 2026

Summary of Changes ​

✨ New Features ​

  • Automatic Escaping of Mapped Values (FLOW-625, FLOW-1369)
  • New Agentic Task Type (FLOW-1263, FLOW-1343, FLOW-1370)

🐞 Bug Fixes ​

  • HTTP Tasks No Longer Fail When a Header Name Is Blank (FLOW-1365)

⚠️ Upgrade Notes ​

WARNING

Automatic escaping is on for new tasks and off for existing tasks. Tasks created after this release escape mapped values automatically. Existing tasks, including workflow definitions stored in Git, keep their current behaviour until you opt them in. Once a task is opted in through the designer, it can't be switched back.

Before opting in an existing task, review its mappings for manual escaping workarounds, such as replace filters that escape quotes, backslashes or new lines. AireFlow no longer detects and removes these automatically, so leaving them in place may escape values twice.

Detailed Changes ​

✨ New Features ​

Automatic Escaping of Mapped Values (FLOW-625) ​

Description

AireFlow now automatically escapes mapped values to suit where they're going, such as JSON, XML, mutations and URLs. Line breaks, quotes, backslashes and other special characters from form data no longer break HTTP request bodies or mutations. This replaces the manual liquid workarounds that were previously needed. Automatic escaping is set per task definition. New tasks have it switched on by default. Existing tasks keep their previous behaviour and show an option to opt in, which is one-way. Workflow definitions already stored in Git behave as before until they're updated to opt in.

What this means for you

You can map form answers straight into your HTTP tasks and mutations without worrying about what people type. A comment with line breaks, quotation marks or a backslash will no longer cause a task to fail, and you no longer need complicated workarounds in your mappings.

New Agentic Task Type (FLOW-1263) ​

Description

A new Agentic task type lets a workflow hand work to an AI agent. You choose the agent and write a prompt, which can include mapped values from the workflow. The agent's response is saved to the task's state, and the task completes automatically. The task type is available to tenants where it has been enabled.

What this means for you

You can now add AI-powered steps to your workflows, for example to summarise, classify or extract information from submitted data. The results are passed on to later steps automatically, without anyone having to act on the task.

🐞 Bug Fixes ​

HTTP Tasks No Longer Fail When a Header Name Is Blank (FLOW-1365) ​

Description

HTTP tasks with a header whose name had been left blank failed at runtime with an error and were retried. These tasks now run correctly.
