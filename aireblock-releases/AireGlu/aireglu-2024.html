AireGlu Release Notes — 2024 ​

This page contains the AireGlu releases published during 2024.

Version 1.91.6 ​

Release Date: December 9, 2024

🐞 Bug Fixes ​

  • Error displaying certain usage data rows now resolved
  • UI now routes back to variables list following variable save

Version 1.91.5 ​

Release Date: December 5, 2024

✨ New Features ​

  • Size limit when creating variables
  • New usage data page

⚡ Improvements ​

  • Endpoints page performance
  • Add nLog setup to usage data writer and job runner

🐞 Bug Fixes ​

  • Validation warning now cleared on input section when selecting endpoint during Job creation
  • Custom cron schedule now saved when clicking between tabs during job creation
  • Exception during endpoint error email phase now handled and logged correctly

Version 1.90.0 ​

Release Date: October 12, 2024

✨ New Features ​

  • Support retry on endpoint HTTP request tasks

⚡ Improvements ​

  • Display secret type (file or text)

🐞 Bug Fixes ​

  • Expand support for endpoint GraphQL responses in Try It Out UI
  • Allow case-insensitive access to headers via Liquid

Version 1.89.0 ​

Release Date: October 30, 2024

✨ New Features ​

  • Support route mapping export
  • Support upload of files as secrets
  • Support mapping into HTTP request task certificate fields

⚡ Improvements ​

  • Usage data performance improvements
  • XPath and JSONPath parsing performance improvements
  • Improve caching coverage

🐞 Bug Fixes ​

  • Update endpoint list immediately after endpoint deletion
  • Prevent double save of imported endpoints
  • Prevent reset of endpoint list when settings amended after the first page

Version 1.88.1 ​

Release Date: September 23, 2024

✨ New Features ​

  • Add endpoint timings to metrics
  • Add Audit task type
  • Allow configuration of response headers

🐞 Bug Fixes ​

  • Allow export/import of endpoints with basic auth

Version 1.87.1 ​

Release Date: September 2, 2024

🚑 Hotfixes ​

  • Add case sensitivity to custom route mappings

Version 1.87.0 ​

Release Date: September 2, 2024

✨ New Features ​

  • Endpoint Wizard Development - Node configuration

🐞 Bug Fixes ​

  • Metrics displaying duplicate Endpoint Task Values Resolved step

🔧 Maintenance ​

  • Mongo package upgrades
