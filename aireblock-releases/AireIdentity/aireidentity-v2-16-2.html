AireIdentity Release Notes ​

Version: 2.16.2
Release Date: 1st June 2026

Summary of Changes ​

✨ New Features ​

  • Optimised Event Architecture for Roles and Policies (ID-1167)

Detailed Changes ​

✨ New Features ​

Optimised Event Architecture for Roles and Policies (ID-1167) ​

Description

The TenantUserUpdated event — previously published for every affected user when a role or policy changed — has been replaced with dedicated TenantRoleUpdated, TenantRoleDeleted, TenantPolicyUpdated, and TenantPolicyDeleted events. A single event is now published per role or policy change, regardless of how many users are assigned to it.

What this means for you

Saving a role or policy now publishes one event instead of one per affected user. For tenants with large user bases this significantly reduces message queue load and improves the responsiveness of the save action in the Roles and Policies UI.
