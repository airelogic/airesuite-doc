AireFrame Release Notes — 2025 ​

This page contains the AireFrame releases published during 2025.

Version 2.41.0 — Array Datapoint Aggregation ​

Release Date: December 15, 2025

✨ New Features ​

  • Add array datapoint aggregation support in pipeline
  • Support for expired status for AireFlow tasks

⚡ Improvements ​

  • Accessibility improvements
  • Improve search result matching

🐞 Bug Fixes ​

  • Fix issue where Liquid colour formatting wasn't being applied in some visualisations
  • Fix issue where the documentation bot wasn't working on configuration pages
  • Fix issue where dragging a widget into a dashboard while filtered would insert the incorrect widget
  • Fix incorrect colours displaying on a bar chart series
  • Fix issue where reference data wasn't being displayed on a line graph visualisation
  • Fix linked data set filtering

Version 2.40.0 — Configuration Page Design Improvements ​

Release Date: November 27, 2025

⚡ Improvements ​

  • Rework configuration page layout for improved usability
  • Improve speed of visualisation updates

Version 2.39.0 — Performance Improvements ​

Release Date: November 17, 2025

⚡ Improvements ​

  • Reduce lag when using the structural entity selector for large structures
  • Improve visualisation update speeds
  • Normalise dashboard selector sizing

Version 2.38.0 — Custom Theming ​

Release Date: November 6, 2025

✨ New Features ​

  • Added custom theming support

⚡ Improvements ​

  • Improve offline detection performance
  • Improve data visualisation designer
  • Improve search matching
  • Improve upsert API return value
  • Improve subject list configuration form
  • Improve configuration import

🐞 Bug Fixes ​

  • Fix issue where custom colours were not reflected in chart legend
  • Fix issue where clicking the home button removes dashboard selection in subject list
  • Fix issue where configuration imports were failing
  • Fix issue in pipeline designer where max by could not be used within a group

Version 2.37.0 — Performance Improvements ​

Release Date: October 20, 2025

✨ New Features ​

  • Add file upload virus scanning

⚡ Improvements ​

  • Improve speed of cross-subject visualisation updates
  • Improve offline detection to handle different devices better

🐞 Bug Fixes ​

  • Fix issue where clicking back within the visualisation designer would lose all changes
  • Fix issue where subject list tooltip did not strip HTML tags
  • Fix issue where download subject for offline button was shown on the portal site
  • Fix issue where a date time custom field value could not be saved or rehydrated
  • Fix issue where linked data sets would show irrelevant actions

Version 2.36.0 — Visualisation Update Performance Improvements ​

Release Date: September 23, 2025

⚡ Improvements ​

  • Improve speed of visualisation pending updates

Version 2.35.0 — Offline Mode ​

Release Date: September 11, 2025

✨ New Features ​

  • Add offline mode support

⚡ Improvements ​

  • Reduce asset sizes for faster load times
  • Move docs bot button into the top navigation bar
  • Improve order by icon distinction

🐞 Bug Fixes ​

  • Fix issue where subject configuration could not be saved under certain conditions
  • Fix issue where users with no groups could still see tenant-level dashboards
  • Fix issue where phone number field had a zero-adding behaviour in certain cases
  • Fix issue where newly created data sets would not appear in the pipeline designer without a page refresh
  • Fix issue where pipeline title could not be updated
  • Fix issue where the Liquid widget preview would not render like the final widget

Version 2.34.0 ​

Release Date: August 11, 2025

✨ New Features ​

  • Add docs bot to configuration pages
  • Add ability to search users list by email

⚡ Improvements ​

  • Rework order by UI in tables

🐞 Bug Fixes ​

  • Fix data extract selector quirkiness
  • Fix issue where URL parameters were lost after sign-in
  • Fix issue where changing the subject data source did not clear the group caches
  • Fix issue where the UI could freeze when a group aggregate was used on a data extract with many fields
  • Fix issue where if multiple partial subject update requests were fired at the same time, only the last update would be applied

Version 2.33.0 — Linked Data Sets ​

Release Date: June 16, 2025

✨ New Features ​

  • Add Linked Data Sets
  • Allow clipboard write inside iframes
  • Allow dashboard to be created on initial load without clicking the create button

Version 2.32.0 — Stacked Data Sets ​

Release Date: May 29, 2025

✨ New Features ​

  • Add Stacked Data Sets
  • Split pipeline and visualisation configuration into separate items to allow pipeline reuse
  • Introduce subject banner query parameter for more control in embedded contexts

⚡ Improvements ​

  • Improve tree-shaking of libraries to reduce bundle size
  • Improve headless mode for more seamless embedding
  • Auto-redirect to AireIdentity if the user is not logged in and has a target URL
  • Improve collapse/expand icon hover state

🔧 Maintenance ​

  • Remove stacked bar chart visualisation type

🐞 Bug Fixes ​

  • Fix issue where structural entity keys were not validated on the subject upsert API
  • Fix issue where the parent structural entity was not validated on the structural entity upsert API
  • Fix issue where HTML was not rendered correctly in the portal subject selector
  • Fix issue where data sources with configuration values were not being sent correctly to the data source

Version 2.31.0 ​

Release Date: May 1, 2025

✨ New Features ​

  • Add search to data set list
  • Add login redirect URL validation

⚡ Improvements ​

  • Improve configuration navigation

🐞 Bug Fixes ​

  • Fix issue where the create subject mutation was not validating location assignments
  • Fix issue where the group cache could still contain deleted structural entities
  • Fix issue where visualisations could not be created
  • Fix issue where the previous visualisation pipeline was shown when creating a new visualisation
  • Fix AireIdentity user management link
  • Fix issue where two subjects could be created with the same value for a unique field within a short time frame

Version 2.30.0 — Performance Improvements ​

Release Date: April 4, 2025

⚡ Improvements ​

  • Fix performance issues when navigating between the subject list and the subject page
  • Fix issue where form actions would sometimes not show due to slow query performance
  • Improve AireVault value fetching performance
  • Add report issue link to the footer

🐞 Bug Fixes ​

  • Fix issue where policy was not applied correctly to AireFlow actions
  • Fix issue where policy was not applied correctly to array custom fields

🔒 Security ​

  • Fix PDF XSS vulnerability

Version 2.29.0 — Liquid Expression Aggregator ​

Release Date: March 27, 2025

✨ New Features ​

  • Add Liquid expression aggregator as an option in the visualisation pipeline
  • Allow a widget to be toggled on for the portal if it is off

⚡ Improvements ​

  • Improve AireFlow task update error messages
  • Subject updated events are now only sent if the subject custom field values have changed

🐞 Bug Fixes ​

  • Fix issue where the import configuration notification was not shown
  • Fix issue on the subject upsert API where a date time value was never valid
  • Fix issue where | size Liquid filter could not be used on a string value
  • Fix issue where client credentials calls would return 403 even after the permissions were granted
  • Fix issue where due date was not pulled through from form tasks

Version 2.28.0 — New REST APIs ​

Release Date: February 27, 2025

✨ New Features ​

  • Add API support for subject custom field array values
  • Add invite third-party users REST API
  • Set task owner type when actioning tasks
  • Allow customisation of x-axis label positioning on graphs

🐞 Bug Fixes ​

  • Fix issue where visualisation ordering did not work correctly for decimal values
  • Fix issue where it was impossible to clear the country code of a phone number
  • Fix issue where import would not update computed field Liquid expression if that was the only change
  • Fix issue where zooming out in the browser would un-align the widget header
  • Fix issue where create:widget permission was required to edit a widget
  • Fix issue where the visualisation pending update icon did not disappear after the update was complete
  • Fix subject upsert API validation

Version 2.27.0 — Array Custom Fields & Third-Party Portal Users ​

Release Date: February 11, 2025

✨ New Features ​

  • Add support for array custom fields
  • Add support for inviting third-party users to the portal using an email address
  • Add support for re-inviting users to the portal
  • Add create structural entity REST API
  • Add subject portal users REST API

⚡ Improvements ​

  • Apply series formatter to axis tick labels
  • Display resolved Liquid value in the applied filter UI
  • Widget filters are now encoded into the URL on the subject page
  • Add inline Liquid filter toggle button

🐞 Bug Fixes ​

  • Fix issue where data points were not shown if actions failed to load
  • Fix issue where subject upsert location could not be changed
  • Fix issue where changing page size did not reset back to the first page
  • Fix issue where changing the structure type of a structural entity could duplicate the custom field values

Version 2.26.0 — AireFlow Form Tasks ​

Release Date: January 16, 2025

✨ New Features ​

  • Add support for AireFlow form tasks
  • Show user job role in the navigation bar

🐞 Bug Fixes ​

  • Fix issue where form PDFs would not load
  • Fix loading UI bug on the subject overview page

Version 2.25.0 ​

Release Date: January 9, 2025

✨ New Features ​

  • Add Subject Location Change APIs

🐞 Bug Fixes ​

  • Fix iframe auto-popup on mobile devices
  • Fix issue where hovering on a bar chart with a custom colour would cause the bar to disappear
  • Fix issue where Liquid visualisations could show an error when the data was valid
  • Fix issue where a form could not be created if the user had a valid create form policy
