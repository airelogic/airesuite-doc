On this page

AireBlocks Release Notes ​

Welcome to the AireBlocks Release Notes area — your home for the latest platform updates, improvements and fixes across the AireInnovate product suite.

Use this page to quickly find what’s changed, what’s new, and any important upgrade notes that may require customer review or testing.

If you’re looking for a specific release, use the left-hand menu to browse by product and version.

🧭 How to use these Release Notes ​

Each release note page follows a consistent layout:

  • Summary of changes — quick view of what’s included
  • Upgrade notes — actions you may need to take
  • Detailed changes — customer impact (“What this means for you”) and technical detail

The “On this page” menu on the right helps you jump to specific sections.

📌 Need support? ​

If you have questions about a release or want to understand the impact for your organisation, please raise a support request with:

  • product name
  • version number
  • a short description of the query / impact you’re seeing

You can send this request to us using our 'Advice and Guidance' section in our support form located: Click Me

🔎 Looking for something else? ​

  • Visit the User Guides section for help using AireBlocks products
  • Use the search bar to find specific features, fixes or ticket references (e.g. FRAME-2475)
